# Código de conduta

Esta organização é um ambiente educacional. Esperamos comunicação respeitosa, colaboração, honestidade acadêmica e abertura para aprender com erros.

Não são aceitáveis assédio, discriminação, exposição de dados pessoais, plágio, uso indevido de credenciais ou comportamento que impeça a participação segura de outra pessoa.

Dúvidas ou situações sensíveis devem ser comunicadas ao professor responsável de forma privada. Problemas técnicos devem ser registrados em Issues sem publicar informações confidenciais.
