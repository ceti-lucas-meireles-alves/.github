# CETI Lucas Meireles Alves - Repositório de Projetos

Bem-vindo ao repositório oficial de projetos desenvolvidos pelos alunos do curso Técnico em Análise e Desenvolvimento de Sistemas do **CETI Lucas Meireles Alves**.

Este repositório contém os padrões compartilhados pela organização. Os arquivos abaixo podem ser utilizados e replicados nos projetos dos alunos.

## Arquivos da organização

## Como replicar em um projeto de aluno

1. Consulte o `README.md` do projeto.
2. Siga o `CONTRIBUTING.md`.
3. Registre tarefas e problemas usando os templates de Issues.
4. Desenvolva em branch e abra um Pull Request.
5. Use o checklist de `PULL_REQUEST_TEMPLATE.md`.
6. Respeite o `CODE_OF_CONDUCT.md` e as regras de privacidade.

Os arquivos institucionais devem ser adaptados ao contexto do projeto, sem copiar dados pessoais, credenciais ou informações sigilosas.
