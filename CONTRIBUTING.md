# Guia de contribuição

Obrigado por contribuir com os projetos do CETI Lucas Meireles Alves.

## Fluxo padrão

1. Leia o `README.md` do repositório.
2. Abra uma Issue para registrar problema, requisito ou proposta.
3. Crie uma branch com nome curto e descritivo, por exemplo `feat/login` ou `fix/validacao-formulario`.
4. Faça commits pequenos e claros.
5. Abra um Pull Request usando o modelo da organização.
6. Responda às revisões e atualize a documentação.

## Requisitos mínimos

- explique o problema que está sendo resolvido;
- documente como executar e testar;
- não inclua senhas, tokens, documentos ou dados pessoais;
- valide entradas e trate erros;
- considere acessibilidade, privacidade e segurança;
- atualize o README quando o comportamento do sistema mudar.

## Commits

Prefira mensagens no formato:

```text
tipo: descrição curta
```

Exemplos: `feat: adicionar cadastro de usuários`, `fix: corrigir validação de e-mail`, `docs: atualizar instalação`.

## Uso de inteligência artificial

Ferramentas de IA podem ajudar a pesquisar, explicar, testar e revisar código. A pessoa responsável pelo Pull Request deve compreender, validar e conseguir explicar todo código enviado.

Ao usar IA de forma relevante, registre no Pull Request:

- qual ferramenta foi utilizada;
- para qual finalidade;
- o que foi revisado ou alterado manualmente;
- quais testes foram executados.

Não envie para ferramentas de IA credenciais, dados pessoais, informações de alunos ou conteúdo sigiloso da escola.
